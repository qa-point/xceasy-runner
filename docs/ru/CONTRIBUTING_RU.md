# Contribution guide

Прочитайте конституцию, technical guide, code style, нужную spec и ADR. Сохраняйте посторонние изменения. Изменение поведения сопровождается contract regression. Запустите `./scripts/check.sh`, а при изменении execution logic — реальный acceptance максимум на двух simulators. Укажите команды, результаты, schema compatibility, privacy impact и всё непроверенное.
