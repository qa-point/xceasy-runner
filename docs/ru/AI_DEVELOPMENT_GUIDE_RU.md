# Руководство AI-разработки

AI определяет первую причинную ошибку по immutable plan, worker classification, execution summary и связанным evidence. Нельзя угадывать outcome по локализованным logs, повторять product failures, ослаблять validation, раскрывать secrets или автоматически менять expected results. Handoff содержит root cause, evidence paths/reason codes, patch, regression coverage, команды и residual risk.
